## 가정 (사용자 확인 필요)

1. 이력서 페이지는 I 펼침으로 만든다.
2. 주소는 기존 구조를 지킨다. 홈 `/ko/`, `/en/`, 이력서 `/ko/resume/`, `/en/resume/`.
3. 영어 문구는 내가 옮겼다. 프로젝트 영문 이름(I am Headcoach, Teampread, Easy Squad, Sports-Man, Baby Calendar, Gyungchung FC)과 "대사 작업"의 번역(dialogue script)은 추정이다.
4. 새 작업 3건(작업 관리 솔루션, 대사 작업 툴, Slack 알림 봇)은 제목만 싣는다. 상세는 사용자가 쓴다.
5. 글 목록은 2023년 글 5개를 그대로 보여 준다.
6. Smilegate 워드마크는 공식 파일을 고치지 않고 쓴다. 상표 사용 허락은 확인하지 못했다.
7. GitHub 활동 그래프는 뺀다. 라이트·다크는 시스템 설정을 따르고 전환 버튼은 두지 않는다.
