# jaywapp.github.io

Personal portfolio site for Junyoung Park (jaywapp) — built with Next.js 14 and deployed on GitHub Pages.

**Live:** https://jaywapp.github.io

## Tech Stack

| | |
|--|--|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |
| i18n | next-intl (Korean / English) |
| Activity | react-github-calendar |

## Pages

| Section | Description |
|---------|-------------|
| Hero | Introduction and quick links |
| About | Background and skills |
| Experience | Work history timeline |
| Projects | Project highlights |
| GitHub Activity | Contribution graph |
| Contact | Contact information |

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```
